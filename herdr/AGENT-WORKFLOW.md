# 기존 Herdr 작업공간에 Codex·Claude를 연결하기

기존 에이전트와 창을 유지하면서 같은 프로젝트에서 작성·검토를 나누는 절차입니다. 2026-11-15 설치된 Herdr 0.9.5의 명령 도움말로 아래 명령 형식을 확인했습니다. 이번 문서 작성에서는 새 모델이나 에이전트를 실행하지 않았습니다.

## 실제 작업공간 확인

작업 중인 폴더, 창, 에이전트를 먼저 조회합니다.

```bash
herdr workspace list
herdr pane list --workspace WORKSPACE_ID
herdr agent list
```

`WORKSPACE_ID`와 `PANE_ID`는 예시 자리표시자입니다. 과거 문서의 창 ID를 그대로 사용하지 마십시오. 프로젝트 경로가 같은지 확인하고, 이전 대화 탭과 현재 입력 가능한 에이전트를 구분합니다. 기존 창에 다른 작업이 진행 중이면 새 형제 창을 사용합니다.

## 기존 창을 유지한 채 Claude 추가

새 창을 만든 뒤 반환된 ID에 에이전트를 연결합니다. `PROJECT_DIR`에는 실제 프로젝트의 절대 경로를 지정합니다.

```bash
herdr pane split --pane PANE_ID --direction right --cwd PROJECT_DIR --no-focus
herdr agent start review-claude --kind claude --pane NEW_PANE_ID
```

`agent start`는 창을 만들지 않습니다. 대상 창은 대화형 셸 프롬프트 상태여야 합니다. 명령 성공은 해당 창에서 예상 에이전트가 감지되고 입력 준비 상태가 된 것을 뜻합니다. Claude 설치·인증은 별도 전제이며, 이 저장소에 계정 인증 정보를 넣지 않습니다.

이전에 숏줍 작업공간에서 기존 Codex를 보존한 형제 창에 실제 Claude를 연결했습니다. 해당 사례의 창 ID와 작업 이름은 현재 환경의 값이 아닙니다. `HERDR_ENV` 환경변수 하나의 유무만으로 연결 가능 여부를 판단하지 않습니다.

## 같은 산출물 검토

Codex와 Claude의 작업 폴더를 같은 공유 프로젝트로 맞춥니다. `AGENTS.md`, `CLAUDE.md`, `HANDOFF.md`처럼 역할과 현재 상태를 담은 프로젝트 문서를 함께 읽게 합니다. 이전 대화 파일을 옮긴 것과 해당 경로에서 기존 세션을 재개할 수 있는 것은 다릅니다.

변경된 작업 폴더에서 Claude의 이전 세션 재개가 실패한 이력이 있습니다. 재개 가능 여부를 확인하고, 실패하면 원래 대화는 보존한 채 공유 인수인계를 읽는 새 에이전트를 시작합니다. 신뢰 확인이나 권한 요청을 우회하지 않습니다.

검토 대상의 정확한 파일·버전·해시를 고정합니다. 작성, 검토, 수정, 재검토 순서를 사용하고 수정 후에는 같은 최종 파일을 다시 검토합니다. 검토 횟수와 중단 조건을 정해 무한 반복을 피하고, 미해결 사항과 사용자 결정이 필요한 항목을 기록합니다.

검토 프롬프트를 보내는 명령 형식은 다음과 같습니다. 실제 전송은 모델 작업을 시작할 수 있으므로 요청과 예산 범위 안에서만 실행합니다.

```bash
herdr agent prompt review-claude '검토할 정확한 파일과 기준을 여기에 지정' --wait --timeout 60000
```

`--wait`는 에이전트 상태 관찰입니다. 검토 내용이 옳다거나 공동승인에 도달했다는 증거가 아닙니다. 이미 작업 중인 에이전트에는 그 작업의 종료가 관찰될 수도 있습니다. 실제 응답, 동일 산출물과 검증 결과를 별도로 확인합니다. Herdr 자체가 합의·검증을 자동 보장하지 않으며 완성된 무인 공동승인 컨트롤러를 이 저장소에 구현한 것도 아닙니다.

## 사용 제한과 세션 유지

현재 사용자 지시로 Gemini·Antigravity의 신규 실행, 협업 호출과 자동 재시도를 제외합니다. 이를 이유로 기존 앱의 provider·예산·서비스 설정을 변경하거나 저장 자료를 삭제하지 않습니다. Codex·Claude도 기존 승인 범위에서 사용합니다.

세션 분리·재접속과 휴대폰 SSH 설정은 [원격 접속 기록](remote/README.md)에 있습니다. 이 자료를 보관하는 것만으로 새 장치의 개발 환경·인증·에이전트 연결이 완성되지는 않습니다.
