# 한글화 당시 빌드·검증 기록

2026-11-06 설치 작업에서 생성된 자료입니다. 이번 업로드를 위해 기존 파일을 읽고 개인 홈 경로를 `~/`로 일반화했습니다. 일시적인 실행 PID는 설치 기록에서 제외했습니다. 실제 사용자 세션이나 대화 로그는 포함하지 않습니다.

| 파일 | 의미 |
|------|------|
| `apply_korean.py` | 최초 표시 문자열 치환 스크립트 원본. 최종 폭·테스트 수정 전체를 생성하지는 않음 |
| `korean.rs` | 새 한국어 화면 테스트의 전체 소스 |
| `before-status.json` | 교체 전 클라이언트·서버 호환 상태 |
| `candidate-status.json` | 후보 바이너리의 기존 서버 호환 상태 |
| `installed-status.json` | 설치 후 상태 |
| `fetch.log`, `rustfmt-install.log` | 의존성·도구 준비 기록 |
| `build.log`, `final-build.log` | 초기 및 최종 최적화 빌드 기록 |
| `fmt.log` | 당시 포맷 검사 기록. 파일이 비어 있음 |
| `tests.log` | 일반 cargo test 시도 기록. SIGPIPE로 끝나 전체 통과 근거로 사용하지 않음 |
| `ui-tests.log` | 중간 단계 UI 테스트 진단 기록. 최종 성공 기록과 구분 |
| `nextest.log` | 전체 실행에서 3,657 통과, 2 실패, 12 건너뜀 |
| `retest.log` | 수정 후 실패했던 두 테스트만 다시 실행하여 통과 |
| `install-record.json` | 설치 시점, 바이너리 해시, 백업과 알려진 한계 |

이 기록은 최종 수정본의 전체 테스트를 새로 실행한 증거가 아닙니다. 최종 소스는 상위 폴더의 기준 커밋·전체 패치·해시로 재구성합니다. 빌드 캐시, Rust/Zig 실행 파일, 패키지 아카이브와 설치 바이너리는 저장소에 중복 보관하지 않습니다.
