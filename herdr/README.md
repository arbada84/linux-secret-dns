# Herdr 0.9.5 한국어 UI 기록

Linux Mint 노트북에 적용한 비공식 한국어 UI 패치를 보관합니다. 공식 Herdr 번역 배포판이 아닙니다. 기존 한국어 패치를 가져온 것이 아니라, 사용자 요청에 따라 Codex가 원본 소스의 표시 문자열을 직접 번역하고 한글 폭 처리와 테스트를 수정했습니다. 설치일은 2026-11-06이며, 현재 파일과 설정의 재확인일은 2026-11-15입니다.

[빌드·설치·복원 절차](BUILD-AND-RESTORE.md)와 [Mint 데스크톱 설정 기록](../docs/linux-mint-desktop-settings.md)을 함께 확인하십시오.

## 보관 파일

| 파일 | 내용 |
|------|------|
| `herdr-0.9.5-ko.patch` | UI 번역, 한글 표시 폭 보정, 관련 테스트 변경. 소스 파일 31개 |
| `manifest.json` | 소스 커밋, 도구 버전, 파일 해시, 확인 범위 |
| `PATCH-FILES.txt` | 변경 파일 31개의 원래 경로 |
| `SHA256SUMS` | 패치·작업 기록의 SHA-256 |
| `history/` | 당시 번역 스크립트, 한국어 화면 테스트, 빌드·테스트 로그, 설치 기록 |
| `config.toml.example` | 현재 노트북 설정인 `onboarding = false` |
| `LICENSE.upstream` | 원본 Herdr의 Apache-2.0 라이선스 |
| `../desktop/herdr.desktop.example` | 사용자 메뉴 등록 예시 |
| `../ghostty/config.ghostty.example` | Ghostty 한국어 설정 예시 |

패치는 [herdrdev/herdr v0.9.5](https://github.com/herdrdev/herdr/tree/v0.9.5)의 커밋 `2ecf19a92fc3a7fff75b6ce3655ef04f4625ec01`을 기준으로 만들었습니다. 번역과 표시 폭 변경은 로컬 수정입니다. 원본 저작권 고지는 유지하며, 패치에 포함된 Herdr 코드에는 원본 라이선스가 적용됩니다. 원본 저장소에는 별도의 NOTICE 파일이 없었습니다.

## 한글화 범위

주요 메뉴, 설정 창, 우클릭 메뉴, 에이전트 목록, 모바일 화면, 상태 표시, 온보딩, 단축키 도움말을 번역했습니다. 명령어, 설정 키, 프로토콜, 세션 데이터, 사용자 지정 이름은 바꾸지 않았습니다. CLI 도움말과 일부 서버 메시지는 영어로 남아 있습니다.

한글은 터미널에서 보통 두 칸을 차지합니다. 패치는 `UnicodeWidthStr` 기반 표시 폭을 사용하도록 버튼 폭, 클릭 영역, 배너, 도움말과 에이전트 행을 보정합니다. UTF-8 바이트 수나 문자 수를 터미널 칸 수로 계산하면 글자와 클릭 영역이 어긋날 수 있습니다.

## 확인된 결과와 한계

2026-11-15 노트북에서 다음 항목을 다시 확인했습니다.

- 설치 바이너리는 Herdr 0.9.5이며 설치 당시 SHA-256과 일치합니다.
- 보관 패치는 현재 소스 작업본의 `git diff HEAD --binary`와 일치합니다.
- 기준 커밋의 깨끗한 소스에 패치를 실제 적용한 뒤, 변경 파일 31개가 현재 소스와 바이트 단위로 일치함을 확인했습니다.
- 클라이언트와 실행 중인 서버는 protocol 22, endpoint generation 1이며 호환 상태입니다.
- Ghostty 1.3.1의 `language = ko_KR` 설정 검사가 통과했습니다.

설치 당시 전체 nextest 실행은 3,657개 통과, 2개 실패, 12개 건너뜀으로 끝났습니다. 실패한 두 테스트의 고정 영문 폭 기대값을 수정한 뒤 해당 두 개만 다시 실행해 통과했습니다. 최종 수정본의 전체 테스트를 다시 실행한 기록은 없습니다. 두 결과를 합쳐 최종 전체 테스트 통과로 표시하지 않습니다.

설치 당시 새 클라이언트에서 주요 한국어 화면을 확인했습니다. 이번 문서 정리에서는 실행 중인 작업을 보호하기 위해 Herdr 서버나 Ghostty를 재시작하지 않았고, 새 장치 빌드나 실제 한글 입력 시험도 수행하지 않았습니다.

공식 업데이트가 `~/.local/bin/herdr`를 교체하면 한글화가 사라질 수 있습니다. 새 버전에 이 패치를 그대로 적용하지 말고 기준 커밋과 적용 가능 여부를 확인하십시오.

## 세션과 인증의 경계

`~/.config/herdr/config.toml`은 설정 파일입니다. `session.json`과 `session-snapshots/`는 작업공간 기록이며, `*.sock`은 실행 중인 프로세스의 통신 소켓입니다. 이 저장소에는 실제 세션, 대화, 소켓, 로그, SSH 키, 모델 인증 정보를 올리지 않았습니다.

Herdr는 터미널 작업공간 관리자이고 Ghostty는 터미널 에뮬레이터입니다. Herdr는 Mint 기본 터미널에서도 실행할 수 있습니다. 설치·한글화를 이유로 기본 터미널이나 기존 세션을 바꿀 필요가 없습니다.

## 직접 작성한 번역과 작업 기록

`herdr-0.9.5-ko.patch`에는 수정한 31개 파일의 변경 내용 전체가 있습니다. 번역뿐 아니라 표시 폭 보정, 기존 테스트 기대값 수정, 새 한국어 화면 테스트도 포함합니다. 원본 커밋에 이 패치를 적용하면 당시 최종 수정 소스를 재구성할 수 있습니다. 원본 소스 전체나 빌드 캐시를 중복 보관하지 않습니다.

`history/apply_korean.py`는 당시 첫 문자열 치환에 사용한 스크립트 원본입니다. 스크립트 안에 영문·한국어 대응표가 있습니다. 이후 수동으로 고친 폭 계산과 테스트까지 생성하지는 않습니다. 따라서 최종 결과의 재현에는 패치를 사용합니다. 이력 스크립트를 이 저장소에서 실행하지 마십시오. 원래 스크립트는 Herdr 소스의 `.local/apply_korean.py` 위치를 전제로 합니다.

`history/korean.rs`는 새로 작성한 테스트의 전체 소스이며 원래 위치는 `src/client/shell/tests/korean.rs`입니다. 테스트는 106×30, 80×24, 44×30 화면의 메뉴·설정·도움말 표시를 확인합니다. 단독 실행 파일이 아니며 원본 Herdr 테스트 모듈에 포함됩니다.

`history/nextest.log`, `history/retest.log`, `history/final-build.log`는 설치 당시 결과입니다. `history/install-record.json`은 당시 설치 기록에서 개인 홈 경로를 `~`로 바꾸고 일시적인 프로세스 ID를 뺀 자료입니다. 이번 문서 정리 시 새 빌드나 전체 테스트를 실행했다는 뜻은 아닙니다.

Ghostty의 한국어 메뉴는 Ghostty가 제공한 번역 파일과 `language = ko_KR` 설정을 사용했습니다. Herdr의 직접 작성한 소스 패치와 구분합니다.

보관 자료의 무결성은 `herdr/`에서 `sha256sum -c SHA256SUMS`로 확인할 수 있습니다.

## 후속 입력·실행·협업 구성

11월 12일에 추가한 Ghostty 1.2.3 한글 입력용 구성은 [별도 실행 구성](../ghostty/1.2.3/README.md)에 있습니다. 시스템 Ghostty 1.3.1을 교체한 것이 아닙니다. [실행기와 아이콘 템플릿](launchers/), [입력 조사 자료](../ghostty/ime-history/README.md), [휴대폰 SSH 설정 예시](remote/README.md), [Codex·Claude 협업 절차](AGENT-WORKFLOW.md)를 함께 보관합니다.

설치 전후 상태와 중간 실패 로그는 [작업 기록 목록](history/README.md)에서 구분합니다. 실제 실행 세션·계정 인증·SSH 키·전체 사용자 로그·대용량 도구 캐시는 공개 저장소의 대상에서 제외합니다.
