# MSI 프로젝트별 Herdr 환경

2026-11-15에 각 노트북 작업공간의 담당 에이전트가 MSI 환경을 구성하고 기록했습니다. 기존 서버와 원본을 보존하며 세 프로젝트를 분리했습니다. 공통 상태는 **독립 작업본·도구·이력 전송·두 창 구성과 가능한 검사 완료, 최초 사용자 설정 및 실제 대화 로딩 확인 대기**입니다.

## 작업공간 목록

| 작업공간 | MSI 독립 작업 폴더 | 좌우 에이전트 | 환경 기록 |
|---------|------------------|--------------|----------|
| 타닥 | `~/Projects/tadak-keyboard` | `tadak-codex` / `tadak-claude` | [타닥 환경](tadak.md) |
| 숏줍개발 | `~/Projects/shorts-automation` | `msi-shorts-codex` / `msi-shorts-claude` | [숏줍개발 환경](shortjup-development.md) |
| 숏줍대본 | `~/Projects/shortjup-new-prompts` | `scripts-codex` / `scripts-claude` | [숏줍대본 환경](shortjup-scripts.md) |

MSI의 기본 Herdr 세션에서 당시 타닥은 `w2`, 숏줍개발은 `w3`, 숏줍대본은 `w4`였습니다. 각 작업공간은 탭 하나와 창 두 개이며, 기존 홈 작업공간도 유지했습니다. 다른 장치의 같은 창 ID와 혼동하지 마십시오. 다음 명령은 MSI의 해당 Herdr 서버를 대상으로 실행합니다.

```bash
herdr workspace list
herdr agent list
```

프로세스와 작업 폴더는 실제 조회했습니다. Herdr의 `idle`과 `interactive_ready`는 최초 확인 화면에서도 관찰됐으므로 대화 로딩 완료 근거로 사용하지 않습니다.

## 도구와 설정 경계

MSI는 기존 Herdr 0.8.8 서버를 유지합니다. 노트북의 Herdr 0.9.5 비공식 한국어 빌드와 버전·UI가 동일하지 않습니다. 기존 서버나 다른 작업공간을 종료·교체하지 않았습니다. 확인한 공통 CLI는 Codex 0.169.0, Claude Code 2.1.321, Node 24.16.0, Python 3.12.3입니다.

세 작업본에 pstack 0.15.36 스킬 58개를 프로젝트 범위로 노출했습니다. 연결 방식은 프로젝트에 따라 상대 링크, 프로젝트별 도구 사본, Claude의 `--plugin-dir`로 다르며 전역 스킬·provider·예산을 덮어쓰지 않았습니다. 실제 런타임 스킬 로딩은 최초 설정 이후 확인해야 합니다.

## 전송·검사 결과

| 프로젝트 | 이력 전송 | 수행한 검사와 한계 |
|---------|-----------|------------------|
| 타닥 | Codex 121개 세션, Claude 프로젝트 대화 1개 | 전체 자료 내용 체크섬, 원본·대상 각각 950,823개 항목 메타데이터, 대표 이력과 APK 산출물 해시. Android 실행 환경과 REA MCP 연결은 미검증 |
| 숏줍개발 | Codex 613개, Claude JSONL 326개 | 새 venv·`pip check`, Gateway 의존성, 외부망 차단 상태의 Python 회귀 146개·Node 테스트 11개·자체 검사. 전체 저장소 검사 통과를 의미하지 않으며 기존 전체 검사 실패 20개는 별도 기준선 |
| 숏줍대본 | 선택한 Codex 3개, Claude 1개 | 자료 체크섬·이력 해시, JSON 340개 구문, Python 1개 AST, PNG 크기·해시, 기존 패키지 import. 원래 루트 Git 저장소나 Node 명세가 없어 임의 생성하지 않음 |

프로젝트 이력만 범위를 정해 복사했습니다. 대화 원본과 노트북·초기 MSI 보관본은 유지합니다. 인증, 개인키, 도구 상태 DB 전체와 운영 DB를 일괄 복사하지 않았습니다. 실제 이력 파일과 대화 ID는 비공개 이관 기록에 남기고 공개 저장소에는 넣지 않습니다.

## 최초 사용자 설정 대기

| 대상 | 실제 관찰한 화면 또는 상태 |
|------|-------------------------|
| 타닥 Codex | 새 작업 폴더 신뢰 확인 |
| 숏줍개발 Codex | 새 작업 폴더 신뢰 확인 |
| 숏줍대본 Codex | `Hooks need review`, 새로 추가되거나 바뀐 훅 1개 검토 |
| 세 Claude 창 | 최초 실행 테마 선택 |
| Claude 인증 조회 | 최신 확인에서 `loggedIn: false`, 사용자 로그인 필요 |

신뢰·훅·테마·로그인 화면을 자동 선택하거나 권한 우회 옵션을 사용하지 않았습니다. 훅은 신뢰 후 sandbox 밖에서 실행될 수 있으므로 폴더 신뢰와 별도로 내용을 검토해야 합니다. 초기 화면을 처리한 뒤 추가 확인이 나올 수도 있습니다.

실제 대화 표시, 새 분기 세션, 현재 작업 경로, 인수인계 응답과 pstack 로딩은 아직 최종 확인되지 않았습니다. 이 단계가 끝나야 에이전트를 작업 준비 완료로 기록합니다. 기존 에이전트 이름이 보이거나 이력 파일이 존재하는 것만으로 완료로 표시하지 않습니다.

## 운영 자료와 개발의 분리

이번 요청은 환경과 작업 연속성 구성입니다. 새 대본·이미지·기능 개발을 자동 재개하지 않았습니다. 초기 안내도 인수인계를 읽고 상태를 확인한 뒤 대기하는 범위입니다.

Fold3의 기존 운영 정본과 봇·큐·예약·DB·미디어는 유지합니다. MSI를 운영 노드로 등록하지 않았습니다. 원본 삭제, 운영 서비스 시작, 새 유료 API, Gemini·Antigravity 호출·재시도, provider·예산 변경은 수행하지 않았습니다.

각 작업본에서 환경과 이력을 확인한 후에 다음 개발 지시를 적용합니다. 노트북과 MSI에서 같은 변경을 동시에 편집하지 않도록 작업 위치를 명확히 합니다. 초기 설정 선택은 운영 실행 승인과 별개입니다.
