# 휴대폰 SSH에서 Herdr에 접속하기 위한 설정 기록

노트북에 남아 있는 휴대폰 접속용 SSH 추가 설정을 공개용으로 일반화했습니다. 실제 휴대폰 주소와 운영 계정명은 제거했습니다. SSH 개인키, 로그인 비밀번호, 저장 인증 정보는 포함하지 않습니다.

`99-herdr-phone.conf.template`은 특정 사용자와 특정 Tailscale 주소를 허용하는 과거 설정의 예시입니다. `historical-effective-settings.redacted.json`은 당시 `sshd` 유효 설정 비교 결과입니다. 대상 휴대폰, 다른 주소, 로컬 이력 동기화와 역방향 연결 계정의 차이를 기록합니다. 실제 휴대폰의 로그인·Herdr 재접속을 이번에 다시 시험한 결과는 아닙니다.

## 적용 전에 확인할 사항

이 파일을 그대로 `/etc/ssh/sshd_config.d/`에 복사하지 마십시오. `USER`와 `PHONE_TAILSCALE_IP`는 자리표시자입니다. 특히 `AllowUsers`는 전체 SSH 접속 허용 대상에 영향을 줄 수 있습니다. 기존 동기화·역방향 연결 계정과 다른 drop-in의 규칙을 함께 확인해야 합니다.

기존 관리자 연결을 유지한 상태에서 원본을 백업하고 다음 구문 검사를 수행합니다.

```bash
sudo sshd -t
```

주소별 적용값은 실제 사용자·접속 주소·호스트명을 지정한 `sshd -T -C`로 비교합니다. 아래 자리표시자는 실제 값으로 바꾸어야 합니다.

```bash
sudo sshd -T -C user=USER,addr=PHONE_TAILSCALE_IP,host=CLIENT_HOST
```

접속 대상뿐 아니라 기존 동기화 계정의 인증 방식, TTY와 강제 명령이 유지되는지도 확인합니다. 확인 전에 SSH 서비스를 재시작하거나 기존 연결을 닫지 마십시오. 이 저장소는 SSH 정책을 자동 적용하지 않습니다.

## Herdr 작업을 계속하기

같은 사용자로 SSH 접속한 뒤 `herdr`를 실행해 기존 서버에 붙습니다. 이름이 있는 세션은 `herdr session list`로 확인하고 `herdr session attach NAME`으로 연결합니다. 이것은 터미널 UI 접속이며 노트북 GUI 화면을 그대로 전송하는 기능이 아닙니다.

Herdr 0.9.5 기본 키 설정에서 `Ctrl+B`를 누른 뒤 `Q`는 클라이언트 연결 해제입니다. 사용자 키 설정이 바뀌었다면 실제 단축키 도움말을 확인하십시오. 작업을 유지하려면 셸의 `exit`, pane 종료, 서버 종료와 구분해야 합니다. 종료·재부팅은 프로세스를 끝내고 절전은 작업과 접속을 중단시킬 수 있습니다.
