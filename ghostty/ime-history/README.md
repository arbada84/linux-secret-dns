# Ghostty 한글 입력 조사 자료

2026-11-12 작업의 시험 스크립트와 결과를 보관합니다. 개인 홈 경로를 `~/`로 바꾸었습니다. 임시 폴더 경로와 GUI 환경 의존성이 남아 있으므로 원본 보존용이며 그대로 실행하는 도구가 아닙니다. 특히 Python의 `Path('~/...')`는 명시적으로 `expanduser()`를 호출하지 않으면 홈 경로로 확장되지 않습니다.

- `initial-ibus/`: 최초 수동 입력 시험과 실패 결과입니다.
- `preedit/`: 조합 중 표시를 분리한 수동 시험과 실패 결과입니다.
- `isolated-xvfb/`: Xvfb·Muffin·Fcitx로 격리 실행을 시도한 스크립트와 로그입니다. 창이 생성되지 않아 입력 결과를 얻지 못했습니다.
- `version-123/`: Ghostty 1.2.3 별도 비교 창과 수동 입력 일치 결과입니다.

스크립트는 당시 시험용 폴더에 결과를 쓰고 프로세스를 생성하거나 종료합니다. 이번 보관 작업에서는 실행하지 않았습니다. 실행하려면 새 격리 폴더와 의존성을 준비하고, 고정 경로와 종료 대상이 새 시험 프로세스만 가리키는지 먼저 검토해야 합니다.

민감할 수 있는 실제 입력 전체를 새로 수집하지 않았습니다. 보관 결과 JSON은 시험 문장 일치 여부와 길이 중심입니다. 세션 소켓, 입력기 사용자 설정 전체, 실행 중인 프로세스 상태, 바이너리와 캐시는 포함하지 않았습니다.
